# Planejamento da landing page VemMED

## Objetivo

Criar uma landing page para vender conteudo preparatorio para vestibulares e ENEM, com foco em candidatos que desejam ingressar no curso de Medicina.

## Publico

- Vestibulandos interessados em Medicina.
- Estudantes que utilizam o ENEM como principal forma de ingresso.
- Pessoas que buscam materiais de estudo organizados, praticos e direcionados para aprovacao.

## Ferramentas e infraestrutura

- Astro
- GitHub
- Cloudflare Pages
- Vercel

## Direcao visual

- Usar as imagens de referencia fornecidas como base para o tema.
- Preservar a identidade visual e a atmosfera das referencias, sem necessidade de copia rigida.
- Priorizar clareza, credibilidade, apelo para estudantes de Medicina e foco em conversao.

## Ativos

Os links, imagens e videos fornecidos estao documentados em `REFERENCIAS.md`.
